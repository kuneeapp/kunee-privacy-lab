# Security for the KUNEE Privacy Lab

## Scope

This is a sample-only documentation repository. It is not a production application, does not provide a supported public-funds workflow, and does not establish a security or privacy guarantee. Browser-based lab activity is confined to an ephemeral local chain (chain ID `31337`); it has no public mainnet access.

## Reporting a concern

Please do not publish exploitable vulnerability details, secret material, wallet private material, recovery phrases, or private keys in a public issue or contribution. Send a concise description of the concern to [support@kunee.app](mailto:support@kunee.app), including affected documentation or behavior and safe steps to reproduce where possible. Do not send credentials or private wallet data.

## Safe handling

- Never commit secrets, private keys, recovery phrases, credentials, or personal data.
- Treat all local test artifacts as disposable and all experimental behavior as unreviewed unless authoritative project documentation says otherwise.
- Verify network and transaction details independently before interacting with any blockchain system.

This policy is for reporting concerns about this sample repository; it does not promise a response time or imply a public release.
